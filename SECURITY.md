# Security Policy
This document outlines the security policy and procedures for the mission-escape project.

## Supported Versions
We currently provide security updates for the `main` branch of this repository.

| Version | Supported |
| ------- |-----------|
| `main`  | :white_check_mark: |
| Other   | :x:       |

## Reporting Security Vulnerabilities
**Please do not report security vulnerabilities through public GitHub issues, pull requests, or discussions.**

Instead, please report all vulnerabilities through either of the supported channels:

1. **GitHub:** Go to the Security tab in this repository and click **Report a vulnerability**.
2. **Direct Portal:** Submit your report, logs, or PoC scripts directly to our login-free queue at [SOLDEV Support Portal](https://solostemple.atlassian.net/servicedesk/customer/portal/39)
